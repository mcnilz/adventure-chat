Bodenpunkt

Punkte definieren die begehbare Fläche oder Hindernisgrenzen.

Hindernis-Fläche

Ganze Fläche ausgewählt. Ziehe auf der Karte, um die gesamte Fläche zu verschieben.

📍 Startpunkt (Spawn)

Definiert die Einstiegsposition für Spieler in diesem Raum.

🚪 Raum-Ausgang

Verbindet diesen Raum mit einem Zielraum und einem Ziel-Spawn.
