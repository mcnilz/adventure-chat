# Lokaler Issue-Tracker
Die Spezifikation liegt in SPEC.md. Arbeitspakete liegen einzeln unter .scratch/adventure-chat/issues/ mit zweistelligem Präfix und sprechendem Namen.
Dies sind absichtlich dauerhafte Projektdateien. Bei späterer Git-Einrichtung sicherstellen, dass dieser Pfad versioniert wird.

Jedes Ticket enthält What to build, Blocked by, Status und Acceptance criteria. Die Startzustände sind draft, da die vorgeschlagene Zerlegung noch nicht abgenommen ist.
Statuswechsel nach PLAN.md. Ein Ticket kann nur begonnen werden, wenn seine Blocker done sind und der Benutzer das Paket bestätigt hat.
Beim späteren Aufruf von setup-matt-pocock-skills diese vorhandene Konfiguration lesen und erhalten. Kein externer Tracker konfiguriert. Lokale Tickets nicht zusätzlich in GitHub veröffentlichen.

Abschlussbelege im Ticket ergänzen: tatsächliche Checks, Review-Ergebnisse, Commit falls vorhanden, menschliche Abnahme. active-state.md bleibt ein kurzer Zeiger.
